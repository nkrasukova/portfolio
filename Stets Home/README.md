**Название:** Проект «Stets Home» — прототип системы умного дома.

**Роль:** Системный аналитик (учебный проект).

**Задача:** Спроектировать MVP приложения для управления освещением на основе интервью с заказчиком и пользователями:

1. Разработать карту пользовательских историй и выделить на ней MVP (Miro), для историй, которые войдут в MVP, написать критерии и сценарии приёмки с помощью языка Gherkin
2. Смоделировать процессы, используя диаграмму потоков данных (DFD) (Draw.io), контекстного и логического уровня.
3. Смоделировать данные, используя логическую ER-диаграмму в нотации Crow’s foots.
4. Разработать словарь данных
5. Разработать прототип приложения «Stets Home» в Figma.
6. Разработать программу и методику испытаний (ПМИ).

**Инструменты:** Miro, Draw.io, Figma.
