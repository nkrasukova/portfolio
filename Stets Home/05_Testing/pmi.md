## TR-1: регистрация в приложении

**Требование:** TR-1

**Предусловия:** -

**Шаги проверки:**

1. Нажать на кнопку "Зарегистрироваться"
2. Заполнить форму регистрации:
    * Указать значение в поле "Имя"
    * Указать значение в поле "E-mail"
    * Указать значение в поле "Пароль"
3. Нажать на кнопку "Зарегистрироваться"
4. Проверить входящие сообщения на почте, указанной при регистрации
   
**Конечный результат:**
* Переход на экран Регистрация
* Все поля формы заполнены валидными данными
* Переход на экран Успешная регистрация
* Проверено поступление письма об успешной регистрации в приложении

### TR-1: Альтернативный сценарий: обработка незаполненных полей
**Шаги проверки:**
1. Нажать на кнопку "Зарегистрироваться"
2. Заполнить форму регистрации: (Не указывать значение в поле "Имя")
3. Нажать на кнопку "Зарегистрироваться"

**Конечный результат:**
* Переход на экран Регистрация
* Рамка незаполненного поля "Имя" окрашена в красный цвет. Под полем отображается подсказка "Укажите имя". Остальные поля заполнены валидными данными.
* При нажатии кнопки "Зарегистрироваться", никаких действий не происходит, кнопка не активна. Регистрация пользователя не доступна.

### TR-1: Альтернативный сценарий: обработка невалидных данных
**Шаги проверки:**
1. Нажать на кнопку "Зарегистрироваться"
2. Заполнить форму регистрации: (Указать невалидные значения в полях)
3. Нажать на кнопку "Зарегистрироваться"

**Конечный результат:**
* Переход на экран Регистрация
* Рамки полей формы регистрации, в которые введены невалидные данные, окрашиваются в красный цвет. Под полями отображаются подсказки.
* При нажатии кнопки "Зарегистрироваться", никаких действий не происходит, кнопка не активна. Регистрация пользователя не доступна.

## TR-2: авторизация в приложении

**Требование:** TR-2

**Предусловия:** Пользователь зарегистрирован

**Шаги проверки:**
1. Ввести валидные данные (E-mail, Пароль)
2. Нажать на кнопку "Войти домой" 

**Конечный результат:** Переход на экран Мой дом

### TR-2: Альтернативный сценарий: введен неверный логин/пароль

**Шаги проверки:**
1. Ввести невалидные данные
2. Нажать на кнопку "Войти домой" 
3. Нажать на кнопку "Попробовать еще раз"
4. Ввести валидные данные
5. Нажать на кнопку "Войти домой"

**Конечный результат:**
* Отображается всплывающее окно "Ошибка. Введен неверный e-mail или пароль. Попробовать еще раз"
* Отображается экран ввода данных
* Переход на экран Мой дом

### TR-2: Альтернативный сценарий: восстановление пароля

**Шаги проверки:**
1. Нажать на ссылку "Нажмите здесь, если забыли пароль"
2. Ввести адрес электронной почты
3. Нажать на кнопку "Восстановить пароль"
4. Перейти в почтовую программу для проверки письма

**Конечный результат:**
* Переход на экран Восстановление пароля
* Переход на экран Сообщение для сброса пароля отправлено
* Письмо получено

## TR-4: управление домом

### TR-4.1: создание нового дома

**Предусловия:** Пользователь авторизован

**Шаги проверки:**
1. Нажать на кнопку "Настройки" в меню приложения
2. Нажать на пункт меню "Управление домом"
3. Нажать на кнопку "Добавить дом"
4. Ввести название дома
5. Нажать на кнопку "Готово"

**Конечный результат:**
* Переход на экран Настройки -> Переход на экран Управление домом -> Переход на экран Добавить дом -> Переход на экран Управление домом. В перечне домов отображается новый дом.

### TR-4.2: добавление гостя (QR-код)

**Предусловия:** Пользователь авторизован

**Шаги проверки:**
1. Нажать на кнопку "Настройки" в меню приложения
2. Нажать на пункт меню "Управление домом"
3. Выбрать дом, в который необходимо добавить гостя
4. Нажать на кнопку "Пригласить"
5. Показать гостю QR-код
6. Нажать на кнопку Готово

**Конечный результат:**
* Переход на экран Настройки -> Переход на экран Управление домом -> Переход на экран Настройки дома -> Переход на экран Семейный доступ -> QR-код отсканирован гостем -> Переход на экран Настройки дома. Гость успешно добавлен в дом и отображается в разделе Участники дома.

#### TR-4.2: Альтернативный сценарий: по ссылке-приглашению

**Шаги проверки:**
1. Нажать на кнопку "Настройки" -> "Управление домом" -> Выбрать дом -> "Пригласить"
2. Ввести адрес электронной почты гостя
3. Нажать на кнопку Готово

**Конечный результат:**
* Ссылка-приглашение получена гостем -> Переход на экран Настройки дома. Гость успешно добавлен в дом и отображается в разделе Участники дома.

### TR-4.3: удаление гостя

**Предусловия:** Пользователь авторизован, Добавлен Гость

**Шаги проверки:**
1. Нажать на кнопку "Настройки" -> "Управление домом" -> Выбрать дом
2. В разделе Участники дома выбрать гостя
3. Нажать на кнопку "Удалить" внизу экрана
4. Нажать на кнопку "Удалить" 

**Конечный результат:**
* Переход на экран Настройки -> Переход на экран Управление домом -> Переход на экран Настройки дома -> Переход на экран Участник дома -> Отображается всплывающее окно Подтверждение удаления -> Переход на экран Настройки дома. Гость успешно удален.

## TR-6: управление комнатами

### TR-6.1: создание комнаты

**Предусловия:** Пользователь авторизован

**Шаги проверки:**
1. Нажать кнопку "+" на экране Мой дом -> "Добавить комнату"
2. Ввести название, выбрать тип, выбрать иконку
3. Нажать на кнопку "Готово"

**Конечный результат:** Отобразилось всплывающее окно Добавление -> Переход на экран Добавить комнату -> Данные комнаты введены -> Переход на экран Управление комнатами. Новая комната создана.

### TR-6.2: редактирование комнаты

**Предусловия:** Пользователь авторизован, Создана комната

**Шаги проверки:**
1. Нажать кнопку "Комнаты…" на экране Мой дом
2. Выбрать комнату -> Нажать на иконку "Редактировать"
3. Ввести новые данные
4. Нажать на кнопку "Готово"

**Конечный результат:** Переход на экран Настройки комнаты -> Переход на экран Редактировать комнату -> Отображаются отредактированные данные комнаты

### TR-6.3: удаление комнаты

**Предусловия:** Пользователь авторизован, Создана комната

**Шаги проверки:**
1. Нажать кнопку "Комнаты…" на экране Мой дом
2. Выбрать комнату
3. Нажать на кнопку "Удалить комнату" -> "Удалить"

**Конечный результат:** Переход на экран Настройки комнаты -> Отобразилось всплывающее окно Подтверждение удаления -> Переход на экран Управление комнатами. Комната удалена.

### TR-6.4: добавление устройства в комнату

**Предусловия:** Пользователь авторизован, Создана комната

**Шаги проверки:**
1. Нажать кнопку "Комнаты…" на экране Мой дом
2. Выбрать комнату -> Нажать на иконку "+" на экране Настройки комнаты
3. Нажать на наименование устройства

**Конечный результат:** Отобразилось всплывающее окно с доступными устройствами -> Устройство добавлено в комнату и отображается в перечне.

### TR-6.5: удаление устройства из комнаты

**Предусловия:** Пользователь авторизован, Создана комната, Устройство добавлено

**Шаги проверки:**
1. Нажать кнопку "Комнаты…" на экране Мой дом
2. Выбрать комнату -> Нажать "Изменить" в карточке устройства
3. Нажать на наименование Комнаты
4. Выбрать пункт "Без комнаты"

**Конечный результат:** Отобразилось всплывающее окно со списком комнат -> Переход на экран Настройки комнаты. Информация об устройстве на экране отсутствует.

## TR-7: управление устройствами

### TR-7.1: включение и выключение лампочки

**Предусловия:** Пользователь авторизован, Устройство добавлено

**Шаги проверки:**
1. На экране Мой дом выбрать устройство
2. На карточке устройства перевести переключатель в "Вкл" / "Выкл"

**Конечный результат:**
* Устройство выбрано -> Переключатель и иконка синие. Устройство включено.
* Переключатель и иконка серые. Устройство выключено.

### TR-7.2: включение и выключение всех лампочек в комнате

**Предусловия:** Пользователь авторизован, Создана комната, Устройство добавлено

**Шаги проверки:**
1. На экране Мой дом в разделе Комнаты… выбрать комнату
2. Нажать на иконку комнаты для вкл / выкл

**Конечный результат:** Иконка комнаты окрашена в синий/серый цвет. Все лампочки в комнате включены/выключены.

### TR-7.3: включение и выключение режима энергосбережения

**Предусловия:** Пользователь авторизован, Устройство добавлено

**Шаги проверки:**
1. На экране Мой дом выбрать устройство -> "Изменить"
2. На экране Настройки устройства перевести переключатель "Энергосбережение" в "Вкл" / "Выкл"

**Конечный результат:** Переход на экран Настройки устройства -> Переключатель окрашен в синий/серый цвет. Режим включен/выключен.
