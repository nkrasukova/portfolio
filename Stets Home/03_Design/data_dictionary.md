# Словарь данных (Data Dictionary)

| Сущность / Атрибут | Описание | Тип данных | Длина | Ограничения / Пример |
| :--- | :--- | :--- | :--- | :--- |
| **Пользователь (User)** | Информация о пользователе системы | | | |
| `email` | Электронный адрес пользователя | String | 100 | Должен содержать `@`. Уникальный. |
| `name` | Имя пользователя | String | 100 | |
| `password` | Пароль к учетной записи | String | 16 | От 8 до 16 знаков, буквы разного регистра. |
| **Дом (House)** | Информация о доме | | | |
| `house_id` | Уникальный идентификатор дома | UUID / Int | | |
| `name` | Наименование дома | String | 50 | |
| **Комната (Room)** | Информация о комнате | | | |
| `room_id` | Уникальный идентификатор комнаты | UUID / Int | | |
| `name` | Название комнаты | String | 50 | Предлагать по типу, добавлять цифру при дубликате. |
| `type` | Тип комнаты | String | 50 | Кухня, Ванная, Коридор, Спальня, Другое. |
| `icon` | Иконка комнаты | File (.jpeg) | | |
| **Устройство (Device)** | Информация об устройстве | | | |
| `device_id` | Уникальный ID устройства (фабричный) | String | 12 | Уникальный 12-значный код. |
| `name` | Название устройства (пользовательское) | String | 50 | Например: "Торшер у дивана". |
| `model` | Модель устройства | String | 50 | |
| `type` | Тип устройства | String | 50 | Лампочка, розетка, датчик движения, термостат. |
| `status` | Статус питания | Enum | 15 | `on`, `off`, `unavailable`. |
| `eco_mode` | Статус энергосбережения | Enum | 15 | `enabled`, `disabled`. |
| `brightness` | Яркость лампочки | Int | | От 1 до 10 000 люменов. |
| `color` | Цвет подсветки | String | 25 | Мягкий белый, тёплый белый, красный, синий и др. |
| **Дом-Пользователь (House_User)** | Связь пользователей и домов (много-ко-многим) | | | |
| `house_id` | Ссылка на Дом | UUID / Int | | |
| `email` | Ссылка на Пользователя | String | 100 | |
| **Сценарий (Scenario)** | Автоматизация действий | | | |
| `scenario_id` | Уникальный ID сценария | UUID / Int | | |
| `name` | Название сценария | String | 30 | Например: "Я ушел из дома". |
| `status` | Состояние сценария | Enum | 15 | `active`, `inactive`. |
| **Расписание (Schedule)** | Время запуска сценария | | | |
| `schedule_id` | Уникальный ID расписания | UUID / Int | | |
| `scenario_id` | Ссылка на Сценарий | UUID / Int | | |
| `weekday` | День недели | Enum | 15 | Понедельник ... Воскресенье. |
| `start_time` | Время начала | Time (HH:MM) | | |
| `end_time` | Время окончания | Time (HH:MM) | | |
| **Сценарий-Устройство (Scenario_Device)** | Какие устройства входят в сценарий | | | |
| `scenario_id` | Ссылка на Сценарий | UUID / Int | | |
| `device_id` | Ссылка на Устройство | String | 12 | |
