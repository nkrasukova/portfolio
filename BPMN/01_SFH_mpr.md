| Пункт | BP1 |
|---|---|
| **Название** | Онлайн-запись и подтверждение визита клиента |
| **Идентификатор** | BP1 |
| **Начало (вход)** | |
| — инициирующее событие | Клиент (зарегистрированный или незарегистрированный) нажимает кнопку «Записаться» на сайте. Альтернативный сценарий — клиент записывается по телефону или лично в барбершопе с помощью менеджера. |
| — ресурсы для создания продукта (результата) | 1. Актуальное расписание мастеров и услуг<br>2. Настроенные менеджером правила и расписание отправки уведомлений<br>3. Контактные данные клиента и выбранный канал связи |
| **Окончание (выход)** | |
| — результирующее событие | Запись создана и сохранена в базе данных, визит клиента подтвержден (или перенесен/отменен), напоминания отработали согласно настройкам |
| — готовый продукт/результат бизнес-процесса | Гарантированная, подтвержденная запись в системе, готовая к визиту |
| **Владелец** | |
| — роль | Менеджер — отвечает за конверсию записи и снижение неявок через настройки системы |
| **Перечень исполнителей бизнес-процесса (роли в задаче)** | 1. Клиент (зарегистрированный или незарегистрированный) — выбирает услугу, мастера, время, канал связи; подтверждает визит по напоминанию.<br>2. Система — проверяет доступность слотов, создает запись, автоматически отправляет напоминания по расписанию, фиксирует подтверждение/отмену.<br>3. Менеджер — вручную создает или корректирует запись при сбоях или по запросу клиента. |
| **Применяемые ресурсы (информационные данные, использованные в бизнес-процессе)** | Расписание мастеров, перечень типов услуг и услуг, каналы связи, данные клиента, шаблоны сообщений (подтверждение, напоминание), правила отправки сообщений |
| **Взаимосвязи с другими основными бизнес-процессами** | Выход BP1 — подтвержденная запись — является триггером и входом для BP2 |
