# Кейс 2: Платформа службы доставки (Delivery Platform)

**Описание:** Проектирование MVP-системы для службы доставки. Платформа агрегирует заказы от поставщиков, распределяет их между свободными курьерами через мобильное приложение и обеспечивает контроль процесса диспетчером.

**Цель:** Оперативный прием и распределение заказов, минимизация ручного ввода данных, автоматизация расчетов с курьерами и поставщиками.

**Область рассмотрения (To-Be):** Жизненный цикл заказа от поступления оператору до начисления оплаты курьеру; взаимодействие ролей (Оператор, Диспетчер, Курьер, Администратор, Бухгалтерия).
