**State table (Таблица состояний).** Доставка заказов (Delivery of orders)

1)  **Цель построения таблицы** - формализовать жизненный цикл каждой ключевой сущности системы службы доставки: закрепить перечень состояний, допустимые переходы между ними, события и их инициаторов. Таблица служит основой для проектирования бизнес-логики будущей системы: рабочего места оператора по вводу заказов в едином формате, мобильного приложения курьера, рабочего места диспетчера, а также точек обмена данными с бухгалтерией - расчетом с поставщиками за доставку и начислением оплаты курьерам.

2)  **Область рассмотрения** - TO BE - проектируемая целевая система.

## Сущность: Курьер
<em><u>Начало:</u></em> администратор зарегистрировал курьера.<br>
<em><u>Окончание:</u></em> учетная запись курьера заблокирована в системе (архив) - допущение<em>.</em>

| Состояние объекта до события | Инициатор | Событие/действие | Условие | Состояние объекта после события |
|:---|:---|:---|:---|:---|
| Начало | Администратор | Администратор зарегистрировал курьера и назначил права доступа | - | Зарегистрирован |
| Зарегистрирован | Администратор / курьер | Курьер получил доступ к мобильному приложению, заказов за ним нет |  - | Свободен |
| Свободен | Курьер | Курьер забронировал свободный заказ | Есть свободные заказы | Выполняет заказ |
| Выполняет заказ | Курьер или диспетчер | Бронь снята: курьер отказался либо диспетчер переназначил заказ другому | Заказ еще не забран | Свободен |
| Выполняет заказ | Система | Заказ доставлен | - | Свободен |
| Зарегистрирован | Администратор | Администратор заблокировал курьера в системе (архив) | - | Исключен |
| Свободен | Администратор | Администратор заблокировал курьера в системе (архив) | - | Исключен |
| Исключен | Система | Учетная запись курьера заблокирована (архив) |  - | Конец |

## Сущность: Оплата курьеру
<em><u>Начало:</u></em> бухгалтерия произвела расчет оплаты курьеру за доставку.<br>
<em><u>Окончание:</u></em> начисленная оплата отражена в личном кабинете курьера.

| Состояние объекта до события | Инициатор | Событие/действие | Условие | Состояние объекта после события |
|:---|:---|:---|:---|:---|
| Начало | Бухгалтерия | Бухгалтерия рассчитала оплату курьеру за доставку заказа | Информация о доставке заказа передана в бухгалтерию (заказ в состоянии «В расчете») | Начислена |
| Начислена | Бухгалтерия | Начисленная оплата передана в систему |  - | Передана в систему |
| Передана в систему | Система | Оплата отражена в личном кабинете курьера |  - | Отражена в личном кабинете |
| Отражена в личном кабинете | Система | Оплата учтена, работу по заказу завершена |  - | Конец |

## Сущность: Заказ
<em><u>Начало:</u></em> заказ поступил в службу доставки от поставщика любым доступным способом.<br>
<em><u>Окончание:</u></em> заказ закрыт (с исполнением) либо отменен без исполнения.

| Состояние объекта до события | Инициатор | Событие/действие | Условие | Состояние объекта после события |
|:---|:---|:---|:---|:---|
| Начало | Поставщик | Заказ поступил в службу доставки от поставщика любым доступным способом |  - | Новый |
| Новый | Оператор | Заказ введен в систему в едином формате и опубликован | Данные полные | Свободен |
| Новый | Оператор | Выявлена неполнота данных, оператор запросил недостающие сведения у поставщика |  - | Уточняется |
| Уточняется | Оператор | Поставщик предоставил данные; заказ дополнен, введен в систему и опубликован |  - | Свободен |
| Уточняется | Оператор (по инициативе поставщика) | Данные не получены в согласованный срок либо заявка отозвана поставщиком | - | Отменен |
| Свободен | Курьер | Курьер забронировал заказ | - | Забронирован |
| Забронирован | Курьер или диспетчер | Бронь снята: курьер отказался либо диспетчер переназначил заказ | - | Свободен |
| Забронирован | Курьер | Курьер забрал заказ в точке выдачи (месте комплектации) | - | Забран |
| Забронирован | Оператор или диспетчер | Заказ отменен до забора курьером | - | Отменен |
| Забран | Курьер | Курьер выехал к клиенту | - |  доставке |
| В доставке | Курьер | Заказ вручен клиенту в месте доставки | - | Доставлен |
| Доставлен | Система | Информация о доставке напарвлена в бухгалтерию для расчета оплаты курьеров | - | В расчете |
| В расчете | Бухгалтерия / система | Оплата курьеру начислена и отражена в личном кабинете; расчет с поставщиком завершен | Расчет завершен | Закрыт |
| Новый | Оператор (по инициативе поставщика) | Заказ отозван поставщиком | - | Отменен |
| Свободен | Оператор | Заказ отменен до бронирования | - | Отменен |
| Отменен | Система | Заказ закрыт без исполнения | - | Конец |
| Закрыт | Система | Заказ архивирован: жизненный цикл завершен | - | Конец |
